Backup Manual

Menyalin seluruh database (pesanan, faktur, stok, pengguna) ke berkas .db di folder backups/. Unduh berkasnya untuk menyimpan salinan di luar server.

Pulihkan dari Berkas Backup

Unggah berkas .db hasil fitur backup ini untuk mengganti seluruh isi database (pesanan, faktur, stok, produk, pengguna). Keadaan sebelum pemulihan dicadangkan otomatis sebagai sebelum-restore, jadi pemulihan yang salah pilih masih bisa dibatalkan. Foto dan unggahan tidak ikut berubah — salin folder uploads secara terpisah bila perlu.

Maksimal 32 MB (batas unggah aplikasi).
