Pembaruan dari Berkas (.zip)

Pakai cara ini bila server tidak punya akses internet. Siapkan arsip .zip berisi folder aplikasi (ada app.py di dalamnya) — misalnya hasil Download ZIP dari GitHub. Database, unggahan, backup, dan konfigurasi tidak tersentuh. Berkas yang tidak ada di arsip dibiarkan seperti semula.

Maksimal 32 MB (batas unggah aplikasi).
Yang Aman dan yang Perlu Diingat
Tidak pernah diubah pembaruan
  • Database toko (*.db) beserta WAL/SHM
  • Folder unggahan (static/uploads/ atau folder data server)
  • Folder backups/ dan berkas konfigurasi
  • Virtualenv (.venv/) dan berkas log
Langkah aman
  • Buat Backup Data sebelum memperbarui.
  • Perbarui saat toko sedang sepi.
  • Setelah selesai, nyatakan ulang layanan (restart) agar kode baru dipakai.
  • Bila versi baru menambah dependensi, jalankan ulang pemasang di server.
